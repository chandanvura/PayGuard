03 / OBSERVABILITY · SRE

See what the system knows.

A practical guide to the signals, rules, dashboards, and logs used to explain PayGuard health.

SIGNAL PATHS
METRICS

Spring Boot → Prometheus → Grafana

Micrometer exports HTTP and payment counters. Prometheus scrapes the endpoint and evaluates recording and alerting rules. Grafana queries it for dashboards.

LOGS

Containers → Alloy → Loki → Grafana

Alloy filters for PayGuard Compose containers, then forwards logs to Loki. Grafana queries them during failure investigation.

TERMS THAT MATTER

Measure behavior, not just uptime.

MetricA numeric measurement over time, such as request count or reconciliation attempts.
LogAn event record: a provider timeout or reconciliation result with context.
SLIA measured service indicator. PayGuard records five-minute availability and 250 ms latency ratios.
SLOA target for an SLI, used to decide when service behavior needs attention.
Error budgetThe allowed failure portion implied by the SLO. Burn rate describes how quickly it is spent.
AlertA Prometheus rule that evaluates when warning, critical burn rate, or latency conditions hold.
Readiness vs livenessReadiness controls traffic; liveness triggers a restart when the process cannot recover.
